// Question 2: Challenges & Problem-Solving:
What was the most challenging aspect of the assignment, and how did you
address it?

// Response:
The most challenging aspect of this project was the battle bool logic. I
had to look up how bools work when calling them in arguments, and then made 
several small programs on the side reminding myself how to use it. Maybe
that is something that I should have been comfortable with by this point but
i've always struggled with them in my previous classes and would simply work
around them, or bash my head against a wall until it worked. This time around 
though, I knew I could not run any longer, and I'm glad I did now. It was like 
something I was avoiding and just had to face now. 

The logic overall for this program made so much sense to me though,
which I am happy about. When I first read the assignment I thought to myself,
"We're making a game? Do I even have the tools for that?" After sitting on
it for awhile, I realized that I can absolutely make a game. Just all the
practices and class assignments I've done before hasn't asked that from 
me. But I knew enough (expect bools apparently..) to make a game.

// Question 3: Testing & Debugging
How did you test your code, and can you describe one example of a bug you
discovered and how you fixed it?

// Response:
I made this program in version iterations. I typically like doing that so that
I can execute the program while adding litte bits to it in each iteration. 
This too helps me see any bugs that may appear with each iteration. Instead of
working tirelessly for longer making this big o'l program and then when I
compile it, there are like 400 bugs and it's just broken. I'd rather deal with 
a dozen bugs at a time than that, and that's hardly even the case.

There was an instance on this program with the bool logic that was bugged. It
was when rolling for hit chances. The hits were not working as intended at
all. Every attack was just missing all of the time. My program currenly has
two lines of code for the bool but before it was like 30 and even two 
functions for player and for enemy. Because I was trying to avoid it..

There was another bug that kept happening where the game would continue going
even if the player lost all HP. It was easy to see that it was my conditional
in the main do while loop. For some reason I was getting && and || mixed up.


****************************************************************************
