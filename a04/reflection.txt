// Question 2: What is the base case for your recursive loot calculation?
Why does it follow child pointers but not parent pointers?

// Response:
The base case is room == nullptr, which returns 0 because there is no
room or treasure to count. The calculation follows child pointers to visit
each room once. Following parent pointers would take us backward to a
previously visited room and could cause endless recursion. 

****************************************************************************


// Question 3: How does your program remember what happened in a room when
the player returns?

// Response:
Each room stores values that remember what happened while exploring, i.e.
root->left = new Room. That memory holds all of the room's values. Moving
between rooms simply changes the currentRoom without creating any new
rooms, so those values stay. When an enemy is defeated, its health stays 
at zero or below, so returning does not start another fight. Collecting 
treasure sets hasTreasure to false, preventing it from being collected 
again. Treasure can only be collected when there is no living enemy in 
the room, including rooms that never had an enemy.
