// Question 2:
Which links change when you insert a node? Which change when you remove the
first node?

// Response:
When inserting a node, the new node's next points to the node that
originally followed the target, and the target's next points to the new
node. When removing the first node, head changes to point to the second
node before the original first node is removed.

// Question 4:
What does the class own, and how do you prevent nodes from being leaked or
deleted twice?

// Response:
The StopList class owns every node allocated with new. The remove bool
deletes the target node after unlinking, and the destructor deletes all the
remaining nodes. Copying the list is disabled so two list objects cannot
accidentally own and delte the same nodes.
